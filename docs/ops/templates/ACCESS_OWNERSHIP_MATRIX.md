# Access Ownership Matrix

| System | Account/Role | Owner | Provider Access Level | Notes |
|---|---|---|---|---|
| Shopify | Store Owner | Client | None | Client retains legal/account ownership |
| Shopify | Collaborator | Client invites Provider | Limited (dev/reporting only) | Least privilege |
| Vercel | Project Owner | Client | Optional maintainer | Restrict to required scope |
| GitHub Repo | Owner/Admin | Client or Provider (per contract) | As agreed | Prefer branch protection |
| Domain/DNS (`xoclub.store`) | Domain owner | Client | None or DNS editor by request | Avoid shared registrar credentials |
| Analytics/Reporting sheet | Owner | Client | Editor | Used for monthly payout proof |
