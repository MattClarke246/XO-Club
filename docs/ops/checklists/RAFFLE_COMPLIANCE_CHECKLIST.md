# Raffle Compliance Checklist (Multi-State US)

This is an operational checklist, not legal advice.

## Legal Review

- [ ] Confirm campaign classification (raffle/sweepstakes/contest) with counsel
- [ ] Identify allowed and excluded states
- [ ] Identify registration/bond requirements by state if applicable
- [ ] Confirm age and residency requirements
- [ ] Confirm no-purchase-required path if needed

## Required Public Documents

- [ ] Official Rules published and linked in raffle UI
- [ ] Eligibility and excluded states published
- [ ] Winner selection and notification terms published
- [ ] Privacy and data use disclosures published

## App Selection (Shopify, no-code first)

- [ ] Evaluate 2-3 Shopify raffle/contest apps
- [ ] Verify anti-fraud controls (duplicate entries, bot checks)
- [ ] Verify draw audit trail/winner transparency
- [ ] Verify legal-rule configuration support for excluded states

## UX and Operations

- [ ] Raffle landing section/banner added to storefront
- [ ] CTA flow tested end-to-end
- [ ] Prize details and deadline clearly shown
- [ ] Winner announcement and proof process defined

## Record Keeping

- [ ] Retain entry logs and draw records for each campaign
- [ ] Retain public rules version used for each campaign
- [ ] Retain winner acceptance and prize fulfillment records
