# Shopify Tenant Setup Checklist

## Account and Billing

- [ ] Create Shopify store
- [ ] Activate paid plan
- [ ] Add verified business details and tax information

## Payments

- [ ] Enable Shopify Payments or approved gateway
- [ ] Validate payout bank account
- [ ] Verify chargeback/dispute notification routing

## Shipping

- [ ] Configure shipping zones
- [ ] Configure shipping rates (standard/express/free thresholds)
- [ ] Set package dimensions and default weights
- [ ] Test shipping label purchase flow

## Taxes

- [ ] Configure tax regions
- [ ] Verify tax collection behavior for target states
- [ ] Validate tax display on checkout test orders

## Policies and Legal

- [ ] Publish Refund Policy
- [ ] Publish Shipping Policy
- [ ] Publish Privacy Policy
- [ ] Publish Terms of Service

## Catalog and Inventory

- [ ] Create products and variants
- [ ] Add inventory quantities per variant
- [ ] Verify SKU and barcode strategy
- [ ] Configure out-of-stock behavior

## Notifications

- [ ] Customize order confirmation email
- [ ] Customize shipping update email
- [ ] Set support contact email and sender domain

## Access and Roles

- [ ] Client owner/admin account finalized
- [ ] Provider collaborator access added (least privilege)
- [ ] Finance/reporting read access assigned
